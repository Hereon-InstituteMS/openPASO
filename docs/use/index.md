# Choose how to use it

There are two ways. Both use the same install and the same solvers; they differ only in where the
AI model comes from.

<div class="grid cards" markdown>

- **[Option A: an AI app](ai-app.md)**

    You already use Claude Code, Claude Desktop, Cursor or another app that supports **MCP**, the
    standard plug that connects tools to AI apps. It costs nothing extra: the app brings the model,
    openPASO brings the solvers.

- **[Option B: your own API key](api-key.md)**

    You have an account at OpenRouter, which gives one key for many AI models, and you pay for what
    you use. You run one command per simulation. Good for scripting and for trying cheap models.

</div>

Not sure? If `claude mcp list` works in your terminal, choose Option A.
